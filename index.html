    スマホ確認ガイド

    1. PCとスマホを同じWi-Fiに接続
    2. PCで python3 -m http.server 8080 --bind 0.0.0.0 を実行
    3. スマホで http://PCのIP:8080 を開く

    公開して確認する場合は Cloudflare Pages / GitHub Pages の無料枠がおすすめです。
