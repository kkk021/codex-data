# ポケモンチャンピオンズ 型紹介サイト（完全無料）

このサイトは **静的ファイルのみ** で動きます。

## スマホで確認する方法

### 方法1: 公開して確認（おすすめ）
1. このリポジトリを GitHub に push
2. Cloudflare Pages（無料）または GitHub Pages（無料）で公開
3. 発行されたURLをスマホで開く

### 方法2: PCのローカルサーバーをスマホから見る
1. PCで以下を実行
   ```bash
   python3 -m http.server 8080 --bind 0.0.0.0
   ```
2. PCとスマホを同じWi-Fiに接続
3. PCのローカルIPを確認（例: `192.168.1.20`）
4. スマホで `http://192.168.1.20:8080` を開く

> 補足: `file://` で直接開くとスマホ確認しづらいので、HTTP配信で確認してください。

## ファイル構成
- `index.html`: UI構造
- `styles.css`: 見た目・レスポンシブ
- `script.js`: 一覧表示、検索、絞り込み、localStorage保存
